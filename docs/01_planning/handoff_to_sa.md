## 現状の理解

### コードベース概要

対象システムはCSCV2025セキュリティコンテストの2層アプリケーション：

**app1** (Python/Django REST API ゲートウェイ):
- JWT認証（djangorestframework-simplejwt）
- ファイルアップロードエンドポイント（ZIP検証付き）
- ユーザー管理（作成、検索）
- ヘルスチェック（SSRF脆弱性あり）
- SQLiteデータベース

**app2** (PHP/Apache ファイルストレージ):
- 7zipアーカイブ展開
- ファイルアップロード処理
- フラグファイル（`/flag.txt`）

### 特定済みの脆弱性（SAで詳細分析が必要）

1. **Path Traversal** — `storage.php` で7zip展開時にパストラバーサル可能な可能性
2. **SSRF** — `health_check()` で任意のモジュールパスにアクセス可能
3. **SQLインジェクション** — `UserViewSet.find()` で `**request.data` を直接使用
4. **ファイルアップロード検証の不完全さ** — ZIP検証のみ、7zip検証なし
5. **空のhealth.php** — ヘルスチェックエンドポイントが機能しない
