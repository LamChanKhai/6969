技術選定理由

Django + DRF

成熟したREST APIフレームワーク。豊富なエコシステムとSimpleJWTとの統合性が選定理由。

PHP/Apache

軽量ストレージサービスとして最適。7z解凍処理とファイル配置に特化したシンプルな設計。

Docker Compose

ローカル環境での再現性確保。ワンコマンドでの起動・停止によりデモ運用を効率化。

2マイクロサービス構成のメリット: 責務分離により、ゲートウェイ（認証・検証）とストレージ（受領・解凍）を独立して開発・デプロイできます。
