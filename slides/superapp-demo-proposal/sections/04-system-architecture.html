Docker Compose 構成

app1 サービス

イメージ: Django/uWSGI
ポート: 8000（公開）
DB: SQLite3（内蔵）
役割: REST API ゲートウェイ、JWT認証、ファイル検証、App2への転送

app2 サービス

イメージ: PHP/Apache
ポート: 内部のみ
ストレージ: flag.txt ボリューム
役割: ファイル受領、7z解凍、storage/<id>/ 配置

docker-compose.yaml
→
app1 (:8000)
↔
app2 (internal)

データフロー — ファイルアップロード

クライアント
→
ZIPファイル送信
→
App1: 拡張子検証
→
App2: 7z解凍
許可拡張子: .txt, .docx, .png, .jpg, .jpeg
App1 処理

1. JWT認証トークン検証
2. ZIPファイル拡張子チェック
3. 許可されたファイルをApp2へ転送
4. 結果をクライアントへ返却

App2 処理

1. ファイル受領（id=ユーザーID）
2. 7zアーカイブ解凍処理
3. storage/<id>/ へ配置
4. 完了レスポンス

ネットワーク構成

外部アクセス

唯一の公開ポート

内部通信

App1 ↔ App2
Docker内部ネットワーク

データ永続化

App1: SQLite3（コンテナ内）
App2: flag.txt ボリュームマウント

セキュリティ: App2は外部から直接アクセスできません。すべてのリクエストはApp1ゲートウェイ経由で処理されます。
ポート公開: App1: 8000（外部公開） |  App2: 内部のみ
