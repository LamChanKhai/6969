コマンド: docker compose up

ステップ5: ファイルアップロード

リクエスト詳細

エンドポイント: POST /gateway/transport/
Headers: Authorization: Bearer <token>
Files: file=@sample.zip
期待結果: "OK"

内部処理フロー

1. JWTトークン検証
2. ZIPファイルの拡張子チェック
3. 許可済み → App2へPOST転送
4. App2: 7z解凍 + storage/<id>/ 配置
5. 完了レスポンス返却

sample.zip
→
App1: 認証 + 検証
→
App2: 7z解凍
→
"OK"

ステップ6: ストレージ確認

確認手順

App2の storage/<user-id>/ ディレクトリに移動し、解凍済みファイルの存在を確認します。

期待されるディレクトリ構造

storage/
└── <user-id>/

  ├── file2.png

ワウモーメント — 5つのハイライト

① ワンコマンド起動

docker compose up で全サービス即時稼働。
反応: 「シンプルで良い」

② エンドツーエンドファイルフロー

アップロードから解凍まで自動処理。
反応: 2サービス連携のスムーズさ

③ 認証ガード付きAPI

JWTトークンなしではアクセス不可。
反応: セキュリティ設計の意識

④ ファイル検証

許可拡張子のみ受け付けるバリデーション。
反応: セキュリティフィルタリング

⑤ ダイナミックスケーリング

uWSGIのcheaperモードによる自動プロセス調整。
反応: 運用効率への配慮
